# 县城赛事内容与数据工作台

为县城 / 小地区的足球、篮球比赛提供录入、运营、看点、战报、拍摄清单的一站式工作台。手机优先，数据本地保存。

## 功能

- **今日**：当天赛程概览、统计、快捷入口
- **赛程**：按日期组织的比赛列表，支持新增 / 编辑 / 删除
- **队伍**：录入队名、地区、队长、简介、核心球员
- **球员故事库**：职业、家乡、经历、技术特点；一键生成短视频选题
- **比分录入**：加减比分、记录进球 / 黄红牌 / 关键事件、MVP、复盘备注
- **积分榜**：足球 / 篮球分别自动计算积分、净胜球、排名
- **G4 赛前看点**：体能、核心、磨合、替补、场地、战意 六维滑杆 → 自动生成看点文案
- **战报生成器**：官方战报、抖音文案、朋友圈、公众号 4 套模板，一键复制
- **拍摄清单**：按当天比赛和项目类型生成赛前 / 赛中 / 赛后必拍镜头，支持勾选记录
- **数据**：JSON 导入 / 导出，载入示例数据，一键清空

## 文件

- `index.html` 页面骨架
- `style.css` 样式（绿色主题、手机优先）
- `script.js` 全部逻辑
- `data.json` 示例数据（可用「数据 → 载入示例」直接导入）

数据持久化使用 `localStorage`，工作完成后用「导出 JSON」备份。

## 本地预览

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

直接双击 `index.html` 也可以使用，但「载入示例」需要 http 服务才能 `fetch` 到 `data.json`。

## 后续可优化方向

1. **PWA**：加 `manifest.json` + Service Worker，可装到手机桌面、离线使用
2. **IndexedDB**：localStorage 上限 5MB；如果开始挂照片/视频缩略图，换 IndexedDB
3. **附件**：每场比赛挂照片、视频片段，配合拍摄清单做素材库
4. **云同步**：可选 GitHub Gist / Firebase / 自建小服务，多人现场协作
5. **战报模板可编辑**：把模板挪到设置页，用户自定义品牌话术
6. **AI 文案润色**：现场录入要点后，调 LLM 生成更生动的稿件
7. **二维码分享**：单场比赛 / 战报生成分享链接和二维码，方便发群
8. **数据可视化**：球员热区、得分趋势、单队历史对战
9. **报名收款**：和招商展示挂钩的报名表 + 收款二维码
10. **多赛事 / 多届**：当前数据是单库，后续按「赛事 / 届数」分库管理
